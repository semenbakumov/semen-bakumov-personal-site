# Личный сайт Семёна Бакумова

Исходники личного сайта для публикации через Timeweb Cloud App Platform.

## Настройки сборки в Timeweb

- Тип приложения: Frontend
- Команда сборки: `npm run build`
- Выходная директория: `dist`
- Версия Node.js: 22

Локальный запуск:

```bash
npm install
npm run dev
```
